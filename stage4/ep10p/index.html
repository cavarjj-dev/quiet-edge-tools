The Return

Name one episode that fits now. Decide if this pass includes the page.

Step 1 only. People rewatch things all the time. Almost nobody names, on purpose, which one episode fits where they are, and whether this pass includes doing the page instead of only watching.

A return is not a guarantee. It is a second look at something you only sort of caught the first time. Not a new stack of strategies.

1. The one episode

Before the next loud week. This stage, or an earlier one. Think about your athlete, the moment they are in, and what is coming up.

2. Ask before you say yours

If another adult is in this with you, ask what they would rewatch before you name yours.

3. Sit with this one

What would you actually see, in the small daily stuff, if this stage had really done something? Not a score. Not a three-week log.
