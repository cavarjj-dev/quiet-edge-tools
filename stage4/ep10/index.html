How to Use This Tool

This is Step 1 only. One trained thing, written before the event. Three events. Loud-minute log.

  1. This week: Before the event, write one thing you already trained that this contest will ask for. One. Not a list.
  2. When it gets loud: Run that thing. Do not invent a new shot.
  3. After: Ran it, searched for a new one, or froze. That is the data.
  4. Week three: Look at the pattern. Keep the trained thing you actually ran.

Knowing "trust your training" is not owning which trained thing you will run.
